Connect your iPad to this PC

Harbor Server is running here. Use this once on each device; Harbor remembers it.

  1. Open the Camera on the iPad and point it at the code.
  2. Tap the link that appears. It opens Harbor in Safari.
  3. Harbor says "Connected to …". Your old server stays as a backup.
Or enter it by hand in Harbor → Connection → Harbor server:
Address __ADDRESS__
Key __KEY__

Keep this page and the link private: anyone with them can browse through your PC's internet connection. To change the key, delete %LOCALAPPDATA%\Harbor Server\access-key.txt and start the server again.
