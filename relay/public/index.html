What this build establishes

It includes a real rewriting proxy, persistent browser storage, and a controlled live connection test. Google/Microsoft login, each game's saves, WebRTC, and iPad Safari remain separate acceptance tests. The relay in this build carries TCP; UDP support is not claimed.
